**图片被找到的过程：**

```python

pattern = r'!\[([^\]]*)\]\(([^\)]+)\)'

if full_path.exists():
    images.append({'path': str(full_path), ...})
```

### 步骤 5: 图片转换为 Base64

**为什么要转换？**
- Claude API 需要 Base64 编码的图片数据

**代码实现：**

```python
# extractors/health_extractor.py

def _encode_image(self, image_path: str):
    # 1. 读取图片文件
    with open(image_path, 'rb') as f:
        image_data = f.read()

    # 2. 转换为 Base64
    image_base64 = base64.standard_b64encode(image_data).decode('utf-8')

    # 3. 判断图片类型
    # sleep_2025-10-25.jpg → image/jpeg

    # 4. 返回 Claude API 需要的格式
    return {
        "type": "image",
        "source": {
            "type": "base64",
            "media_type": "image/jpeg",
            "data": image_base64  # 长长的 Base64 字符串
        }
    }
```

---

### 步骤 6: 发送给 Claude Vision API

**构建 API 请求：**

```python
# extractors/health_extractor.py

# 构建消息内容
content = [
    # 1. 文字提示
    {
        "type": "text",
        "text": """你是健康数据提取助手。请从以下笔记中提取健康数据。

笔记内容:
# 2025-10-25 健康日志

## 睡眠
昨晚睡得不错！

请提取睡眠相关数据，包括总时长、深度睡眠、睡眠质量等。
如果图片中包含数据，请识别并提取。"""
    },

    # 2. 图片数据
    {
        "type": "image",
        "source": {
            "type": "base64",
            "media_type": "image/jpeg",
            "data": "iVBORw0KGgoAAAANSUhEUg..."  # Base64 数据
        }
    }
]

# 调用 Claude API
response = client.messages.create(
    model="claude-sonnet-5",  # 或 OpenRouter
    max_tokens=4096,
    messages=[{
        "role": "user",
        "content": content
    }]
)
```

### 步骤 7: Claude AI 分析图片并提取数据

**Claude 做了什么：**

1. **识别图片内容**
   - 这是一个睡眠监测 APP 的截图
   - 识别出各个文字和数字

2. **理解上下文**
   - 总睡眠时间: 7小时32分 → 7.53小时
   - 深度睡眠: 2小时15分 → 2.25小时
   - 入睡时间: 23:15
   - 起床时间: 06:47
   - 睡眠质量: 85分

3. **生成结构化数据**

```json
{
  "sleep_duration": 7.5,
  "deep_sleep_duration": 2.25,
  "sleep_start": "23:15",
  "sleep_end": "06:47",
  "sleep_quality": "85分",
  "sleep_notes": "深度睡眠2小时15分，浅睡眠4小时50分，REM睡眠37分钟"
}
```

**Claude 返回的完整响应：**

```
{
  "date": "2025-10-25",
  "sleep_duration": 7.5,
  "deep_sleep_duration": 2.25,
  "sleep_start": "23:15",
  "sleep_end": "06:47",
  "sleep_quality": "85分",
  "sleep_notes": "深度睡眠2小时15分，浅睡眠4小时50分，REM睡眠37分钟，睡眠质量评分85分",
```

## 🔍 关键技术点

### 1. Claude Vision API 的强大之处

**不只是 OCR（文字识别）**

```
普通 OCR:
"总睡眠时间: 7小时32分"
↓
提取文字: "7", "小时", "32", "分"

Claude Vision:
"总睡眠时间: 7小时32分"
↓
理解含义: sleep_duration = 7.53
理解上下文: 这是总睡眠时长
转换单位: 7小时32分 = 7.53小时
```

**理解不同的 APP 界面**

Claude 可以识别：
- 小米运动的睡眠界面
- Apple Watch 的睡眠统计
- 其他任何睡眠 APP 的截图
- 甚至手写的睡眠记录！

### 2. 为什么用图片而不是手动输入？

**方便性对比：**

```
手动输入:
├── 总睡眠: 7小时32分 ✍️
├── 深度睡眠: 2小时15分 ✍️
├── 浅睡眠: 4小时50分 ✍️
├── REM: 37分钟 ✍️
├── 入睡时间: 23:15 ✍️
└── 起床时间: 06:47 ✍️
时间: 2-3分钟

用图片:
├── 截图 📸
└── 粘贴到笔记 📋
时间: 10秒钟

精确度: 图片更准确（直接来自设备）
```

### 3. 多张图片怎么办？

**完全支持！**

```markdown
# 2025-10-25 健康日志

## 睡眠
![小米手环睡眠](sleep1.jpg)

## 体重
![体重秤](weight.jpg)

## 运动
![跑步记录](running.jpg)
```

**Claude 会全部识别：**

```json
{
  "sleep_duration": 7.5,      // 从 sleep1.jpg
  "weight": 68.5,              // 从 weight.jpg
  "exercises": [{              // 从 running.jpg
    "type": "跑步",
    "distance": 5,
    "duration": 30
  }]
}
```

## 🎓 总结

### 整个流程的核心

```
你的睡眠照片
    ↓
Obsidian 笔记
    ↓
Python 解析器 (找到图片)
    ↓
转换为 Base64
    ↓
Claude Vision API (识别+理解+提取)
    ↓
结构化数据 (JSON)
    ↓
SQLite 数据库 (永久存储)
    ↓
随时查询、分析、互动
```

### 关键优势

1. **简单**: 截图 → 粘贴 → 完成
2. **准确**: 直接来自设备，避免手动输入错误
3. **智能**: Claude 理解上下文，不只是识别文字
4. **灵活**: 支持任何 APP 的截图
5. **快速**: 几秒钟完成识别

### 你只需要做3件事

1. 📸 截图
2. 📋 粘贴到 Obsidian
3. ▶️  运行 `python cli.py parse --date today`

系统会自动完成剩下的所有工作！
