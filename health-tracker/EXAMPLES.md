## 场景 5: 智能问答

### 问题：为什么这周体重没变化？

```bash
python cli.py chat "为什么我这周体重没变化？"
```

**Claude 的回答：**

```markdown
让我分析一下你这周的数据：

## 可能的原因

### 1. 运动量减少了
对比上周：
- 上周运动：5次，280分钟
- 本周运动：3次，180分钟
- 减少了：100分钟（-36%）

运动量的显著减少可能是体重停滞的主要原因。

### 2. 饮食热量略有增加
从你的记录看：
- 本周有3天外食（餐馆、外卖）
- 周末聚餐摄入较高
- 估算平均每天热量：2200卡（上周1900卡）

### 3. 睡眠质量下降
- 本周平均睡眠：6.8小时（上周7.5小时）
- 睡眠不足会影响代谢和激素水平
- 可能导致更难减重

### 4. 水分潴留
- 最近几天钠摄入较高（外食）
- 可能导致暂时性水分潴留
- 体重不是脂肪增加，而是水分

## 建议

1. **增加运动频率**：回到每周5次的节奏
2. **控制饮食**：减少外食，自己准备健康餐食
3. **改善睡眠**：每晚保证7-8小时睡眠
4. **多喝水**：促进代谢，减少水分潴留
5. **耐心等待**：体重波动是正常的，关注长期趋势

记住，减重不是线性的，偶尔的平台期很正常。继续坚持
健康的生活方式，体重一定会继续下降！
```

## 场景 10: 批量处理历史笔记

### 处理过去一个月的笔记

```bash
# 创建批处理脚本 batch_parse.sh
#!/bin/bash

for i in {1..30}; do
  date=$(date -d "$i days ago" +%Y-%m-%d)
  echo "Processing $date..."
  python cli.py parse --date $date
  sleep 2  # 避免 API 频率限制
done

echo "Done!"
```

```bash
chmod +x batch_parse.sh
./batch_parse.sh
```
